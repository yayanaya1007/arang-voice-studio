# 아랑 보이스 스튜디오

[아랑 보이스 작업실 열기·설치](https://yayanaya1007.github.io/arang-voice-studio/)

각자 컴퓨터에 설치한 아랑 보이스를 웹 화면에서 이용합니다. 첫 설치 시 작업실에서 본인이 비밀번호를 정합니다. 이 공개 사이트에는 프로그램과 업데이트 파일만 있으며, 개인 목소리·대본·결과·비밀번호·API 키는 포함하지 않습니다.

맨 위의 **내 컴퓨터용 앱 다운로드**에서 설치 파일을 받습니다. 기존 앱은 종료한 뒤 설치 파일을 실행합니다. 기존 개인 자료는 보관됩니다. 새 컴퓨터에는 자기 목소리를 직접 등록합니다. 첫 설치에는 실행 환경과 공식 Qwen 파일을 별도로 내려받습니다.

설치 후 **내 작업실 열기**를 누르면 현재 컴퓨터의 작업실이 열립니다. 다른 가족의 컴퓨터에 연결하지 않습니다. 프로그램 실행 중에는 5분마다 서명된 업데이트를 확인하고, 받은 업데이트는 다음 실행에 적용합니다.

설치 파일은 Windows용입니다. 실제 속도와 이용 가능 여부는 각 컴퓨터의 성능에 따라 달라집니다.
